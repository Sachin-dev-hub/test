The VM needs internet access to GitHub, Docker Hub, and Python package repositories. VirtualBox NAT networking normally allows outbound access; a GitHub webhook would need additional inbound connectivity.

Install Git and Python support:
sudo apt update
sudo apt install -y git python3 python3-venv ca-certificates curl

> allow jenkins to run docker
sudo usermod -aG docker jenkins

> Verify access as the Jenkins user:
sudo -u jenkins -H docker version

also checks
sudo -u jenkins -H git --version
sudo -u jenkins -H python3 --version
